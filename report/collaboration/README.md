# 大模型协作记录

本目录保存真实对话摘录、协作工作流、失败与纠正、Ross 套件使用心得和技能验证记录。研发结论需与当前发布源码和对应验证证据核对，不能仅由历史对话中的助手陈述确定。

| 文件 | 内容与范围 |
|---|---|
| `collaboration_record.md` | 提示词、回答摘要、自我纠错、任务分工、Ross 心得及技能沉淀 |
| `public_excerpts.jsonl` | 从维护者原始归档的 54 条消息中选取 15 条真实消息，对本机绝对路径作可见替换 |
| `public_excerpts_metadata.json` | 公开摘录的来源哈希、原行号和替换计数 |
| `evidence_index.json` | 协作正文引用的归档材料路径、SHA256 及 Ross 摘要边界 |
| `privacy_review.json` | 对既有摘录进行的角色/元数据核对与凭据模式检查 |
| `skill_validation.json` | 两项技能的 17 项真实主机检查与独立临时安装校验 |
| `driver_log_classification.json` | 对真实驱动归档日志的离线分层结果 |
| `user_log_validation.json` | 对用户提供历史 Boot、PL、DDR、自启输出的独立离线分类及三模型文件交叉核对 |

完整原始对话及其导出元数据由维护者留存，不随公开仓库分发。公开摘录保留来源会话标识、原始文件 SHA256、角色、时间和来源行号，排除系统/开发者指令、内部推理、工具参数与结果、环境上下文及其他聊天。摘要覆盖部分过程，不代表全程逐字记录。Ross 部分依据维护者保存的历史过程摘要，未附原始 MCP JSONL，因此不把它当作本版综合、时序或上板证据。

用户粘贴的历史板端输出位于 `evidence/linux/board/user_logs/`，包含 `BOOT_DT_PASS`、`PL_ABI_PASS`、`MODEL_PRELOAD_PASS`、`AUTOSTART_ENABLED` 及安装后服务未运行的状态。来源元数据明确执行时间未知、非本次直连执行；不能拼接成同一次冷启动过程。

本目录的文件核对和离线日志分析没有访问板卡。原 17 项技能验证收据不变，新增归档检查单独记录。最终部署身份见发布清单；最终性能与资源结果见设计报告及其引用材料。
