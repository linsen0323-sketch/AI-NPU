## 优先补齐：影响独立复现或公开分发

| 材料 | 当前状态与影响 | 补充后的验收 | 建议位置 |
|---|---|---|---|
| 匹配基础 SD Linux 的公共获取方式 | 本地存在基础 WIC 的身份元数据，但没有公开下载入口；该 WIC 也不含最终应用更新。新用户尚不能取得确定相同的 rootfs | 提供可下载镜像、完整 SHA256、分区/容量说明和许可；或者提供可完整构建它的工程 | `board/linux/rootfs/`、`board/linux/dependencies/` |
| 完整 PetaLinux / Yocto 与启动链配置 | 未归档完整 `project-spec`、rootfs/BSP/配方，以及 BOOT.BIN 使用的 BIF、FSBL/U-Boot 版本和配置。精确内核源码不等于完整 SD 构建链 | 从干净环境生成匹配 rootfs、BOOT.BIN、image.ub，并记录命令和文件身份 | `board/linux/petalinux/`、`build/scripts/linux/` |
| 自有代码许可证与分发授权 | 根许可证仍待维护者确定；第三方和模型/数据集授权独立存在 | 明确版权主体与自有代码许可证，保留文件级标识，确认随包二进制/权重的分发条件 | `license.md`、`docs/third_party.md` |
| ResNet18 首次 FP32→QDQ 生成环节 | 冻结 FP32/QDQ、重定点参数和后续构造工具齐全，但最初量化生成器及完整校准记录未找到 | 归档真实原脚本、校准选择、环境与命令；或者明确此步以冻结中间产物为复现起点 | `src/host/quantization/resnet18/`、`data/calibration/` |
| 最终输入配置的整网 Golden 与板端输出 | 现有 NEU6 主机 Golden 是 640；ResNet 原验证是 224；COCO QDQ/ORT 是主机256结果。没有最终三模型同输入逐项板端比较 | 用最终 160/256/256 配置保存固定输入、参考输出、板端原始输出、数值容差/检测匹配规则与比较结果 | `data/reference/`、`evidence/models/board/` |
| 完整推理与整理后部署路径的冷启动收据 | 原系统上板状态已确认；历史BOOT_DT/PL_ABI/DDR回读和自启动安装输出已归档，但不构成完整连续冷启动；无日期`/opt/npu100`路径适配只有本地检查 | 正常断电上电后保存驱动、模型DDR回读、预览、三模型推理、四键和服务ready的连续日志；记录本版启动/模型/模块哈希 | `evidence/linux/board/` |
| Git LFS / 大文件发布与隐私核查 | 本地实体文件已备，尚未完成本次仓库发布；大文件需按配置获取LFS实体。公开摘录已按任务范围脱敏 | 新克隆可获得 LFS 或 Release 实体并通过哈希；确认无凭据及不应公开的个人信息 | `.gitattributes`、`manifests/`、`report/collaboration/` |

上述条目中，基础镜像公共分发与完整源码构建可以形成两条不同复现路线；若只交付冻结产物部署路线，应明确其前提，不能写成完整基础系统源码重建已闭合。

## 使用现有材料时的口径

- **33.4 倍**对应三模型各执行一张时，`117 s / 3.5 s` 的标量 C 对照；NEON 双核对照为 `11 s / 3.5 s ≈ 3.14 倍`。
- 最终资源为 routed 阶段；Slice 为 `13,299/13,300`。板卡上有画面不证明所有外部 I/O 时序已经建模，时序报告仍保留输入/输出约束提示。
- 主机 FP32 / 量化参考 / QDQ ONNX 精度、RTL Golden、DDR 文件回读和板端任务结果分别记录，不能互相替代。
- 历史验证收据保留原始时间、路径和测试范围；此次整理生成的收据只描述实际执行的本地检查。
- 历史BOOT_DT、PL_ABI、DDR回读和自启动安装不是同一次连续冷启动证据；`AUTOSTART_ENABLED`不代表服务已运行，安装后false状态原样保留。
