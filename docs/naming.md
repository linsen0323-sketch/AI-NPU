# 命名、迁移与修改规则

1. PL源码、约束和BD对应当前npu100.xpr引用集合；PS/Linux取同一npu100/software目录及匹配部署包，不合并旧工程。
2. 外层目录和入口脚本采用稳定英文名称。时间、轮次、临时调试名仅保留在来源记录中。
3. 不因外观统一而修改 RTL 模块名、端口、参数、寄存器地址、模型格式标识、内部文件合同或算法。
4. 第三方 Python 包的导入路径及工具必需名称保留。具体例外由 package_validation.json 列出。
5. 新包中的路径适配属于整理改动。原始文件的 SHA256 与新文件的 SHA256 分开记录，不冒充原板测字节。
6. 历史验证收据作为原始记录保留，不改写其“未上板”“仅静态”等阶段描述；当前状态在新文档说明。
7. 所有来源按硬件、Linux、模型三个独立清单归档，统一汇总为 manifests/source_map.json。
8. 未找到的工程、仿真、数据、报告或板测记录保留明确位置与缺口，不复制不相干旧文件充数。

为确保名称变更没有破坏关联，本包核对 Python 语法、必要的构建/安装脚本以及模型和硬件身份。数学算法、权重和 bitstream 不在本次整理范围内修改。
